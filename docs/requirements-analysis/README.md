## Evidence boundary

The analysis is based on the Laravel routes, middleware, controllers, services,
jobs, Eloquent models, migrations, Blade views, Python service, tests, existing
architecture diagrams, and Phase 3–16 ML reports in this repository. A feature
is marked **Implemented** only when source code and/or regression tests support
it. A feature is marked **Proposed**, **Incomplete**, or **Unverified** when
stakeholder approval, deployment evidence, external data, or source-code
evidence is missing.

The deployed rice-yield model remains **ACCURACY NOT VERIFIED**. Functional
inference is not treated as scientific validation.
