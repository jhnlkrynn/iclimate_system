# Requirements Finalization Gate

## Gate A — stakeholder validation

Pass only when completed responses identify the respondent, role, scope, date, decision, conditions, and supporting artifact. A questionnaire without a decision record is not approval.

## Gate B — evidence acceptance

Pass only when each research file has a checksum, source/custodian, coverage, units, provenance, approval status, duplicate/demo/derived classification, and permitted use. Unsupported records must be rejected or limited to descriptive use.

## Gate C — model compatibility

Pass only when the original training recipe establishes the meaning and preprocessing of all twelve inputs and production reconstruction is compared feature by feature. Until then, farm-specific scientific interpretation is not established.

## Gate D — independent evaluation

Pass only when the target and unit are approved, observations are independent, chronology or season groups do not leak, baselines are defined, and metrics are calculated only from accepted evidence.

## Gate E — Heat Map acceptance

Pass only when each layer has an approved purpose, source lineage, spatial aggregation, freshness, weights/thresholds, minimum evidence, and no-data behavior. Yield-derived layers must not treat demo or unvalidated observations as verified production.
